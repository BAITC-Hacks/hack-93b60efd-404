# Official Voice Router starter kit

`voice_router_dataset/` is the unmodified Case 2 starter kit supplied to HackAlem participants. It describes the fictional Saqta Insurance company and uses synthetic records. The dataset snapshot date is 2026-10-01; the application must use that date for relative date interpretation.

Source: [official organizer-provided Drive file](https://drive.google.com/file/d/1sHE56gXnzdscHz5lMcNbwd1VsJIVLFUv/view). The files are kept together so the organizer's `evaluate.py`, dialogue samples, scenario definitions, and action/knowledge data remain reproducible. Do not insert evaluation-specific phrase rules into the implementation.
